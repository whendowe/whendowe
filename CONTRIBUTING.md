# Contributing

Thanks for looking. For now:

- **Issues are welcome**: bug reports, questions, and descriptions of what you
  tried to arrange and where it got in the way.
- **Pull requests from outside are not being accepted yet.** The licensing
  terms for contributions are not settled, and a merged change can't be
  relicensed later without its author. A PR opened now will be closed with
  thanks, not ignored.
- **Security problems** go through private reporting, never a public issue —
  see [`SECURITY.md`](SECURITY.md).

If you want to run it yourself, `README.md` covers both deployments, and
`DESIGN.md` explains how it works. `AGENTS.md` is the working manual for the
people and agents who do change the code; it is worth reading before you
propose a change in an issue.

This file will change when contributions open.
